## How to Download it on your machine
1. Make sure what platform you are on, Windows or Linux?
* *Currently I develop the linux version on Ubuntu 22.04.5 LTS version, if it is not compatiable with your device, raise the issue here*
2. Go to [dist](https://github.com/Janmayeneric/csv-compression/tree/main/dist) to find the compatiable version based on the suffix
* *win11 means it is developed on windows 11, ubuntu 22.04.5 LTS means it developed on that version of linux
3. Download the executable file based on the page
* For example: if page is https://github.com/Janmayeneric/csv-compression/blob/main/dist/compressor-tool-ubuntu-2204, you need to download it via https://raw.githubusercontent.com/Janmayeneric/csv-compression/main/dist/compressor-tool-ubuntu-2204, I will give the example of how to download the file on linux machine

```bash
wget https://raw.githubusercontent.com/Janmayeneric/csv-compression/main/dist/compressor-tool-ubuntu-2204
```
4. Execute the code based on the directory
```bash
./compressor-tool-ubuntu-2204
```
